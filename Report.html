TechNest: The Modern Single Page Application (SPA)

Course: Computer Engineering - CS3404 GUI Programming
Project Domain: E-Commerce Store (Tech & Gadgets)
API Endpoint: DummyJSON.com REST API

1. Executive Summary & Architecture

TechNest is a Data-Driven Single Page Application (SPA) built using Vue 3 (Composition API), TypeScript, Vite, and Tailwind CSS v4. The application features strict type safety, modular component composition, responsive design across mobile/tablet/desktop viewports, Pinia global state management, Vue Router dynamic routing, dark mode toggle, and DummyJSON REST API authentication integration.

2. Features Implemented

Category Feature Implementation Details
Mandatory Vue 3 & TypeScript Composition API with <script setup lang="ts">. 100% strictly typed frontend architecture (No any types).
Mandatory DummyJSON API Integration Asynchronous REST API fetching using native fetch for product listings, categories, deals, details, and auth.
Mandatory Data Search & Filtering Live text search input filtering across products, category selection filtering, and discount percentage filtering.
Mandatory Detail View Route Dedicated route /product/:id displaying image gallery, availability, shipping, tags, and reviews.

Bonus (Distinction) Global Shopping Cart Pinia global store (cartStore.ts) supporting add/remove, quantity steppers, discount calculations, and persistence.
Bonus (Distinction) Dynamic Routing Vue Router 5 handling routes (/, /categories, /deals, /product/:id, /cart, /login, /support).
Bonus (Distinction) Dark Mode Theme Light/Dark theme toggle using Tailwind's dark: variant and localStorage state persistence.

4. TypeScript Interfaces

All data schemas consumed from DummyJSON API are strictly typed in src/types/index.ts:

  • Product: Strictly types product properties (id, title, price, brand, rating, images, reviews, etc.)
  • CartItem: Types shopping cart items and line item totals
  • Review: Types customer review feedback
  • ProductsResponse: Types paginated API response schema
